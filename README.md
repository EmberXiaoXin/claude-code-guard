# Claude Code Guard

给本机 Claude Code 绑定固定网络出口，并清理旧登录残留。

## 安装

需要 Node.js 22+：

```bash
npx skills add xnydl/claude-code-guard -g -y
```

或解压后按 `INSTALL.md` 拷到 `~/.claude/skills` / `~/.grok/skills`。

新开对话，输入 `/claude-code-guard`。

## 使用前

先在自己的网络工具里选定 **一个固定节点**（推荐台湾），不要用自动切换。
